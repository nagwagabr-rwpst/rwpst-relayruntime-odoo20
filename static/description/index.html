Why RelayRuntime?

Most WhatsApp add-ons stop at sending. RelayRuntime is an Enterprise Messaging Runtime—an execution layer between Odoo and providers that keeps messaging reliable, observable, and operationally controlled.

Operator workflows

Built for attended WhatsApp campaigns on Odoo 20 Community: bulk sending, campaign history, and a delivery log for every contact.

Provider setup

One active provider per company. Green API sends live messages. Mock Provider simulates sends for testing.

Campaign execution

Each campaign runs in the operator's request, recipient by recipient, with delays and a delivery log for every contact.

Operator retry

From a finished campaign, Retry Failed Recipients opens a linked retry campaign for failed and skipped contacts and sends it immediately.

Delivery monitoring

The Delivery Dashboard totals internal send results: sent, failed, and skipped, based on the provider's HTTP response.

Campaign operations

Run Bulk Messaging and Campaign Management from one Command Center with live visibility.

Odoo Community support

Built specifically for Odoo Community teams that need enterprise messaging without Enterprise Edition lock-in.

Clean operator experience

KPIs, alerts, workspaces, and navigation designed for daily operations—not buried technical forms.

Supported Providers

Live sending: Green API. Test mode: Mock Provider. Additional provider adapters are registered but not available for live sending in this release.

Green API

Live sending for attended WhatsApp campaigns.

Mock Provider

Simulated sends for demos and testing. No real WhatsApp messages.

Registered adapters

Meta Cloud API, Evolution API, UltraMsg, Twilio, Gupshup, and Custom are registered and are not available for live sending in this release.

One active provider

Each company uses one active provider configuration at a time.

Mock Provider is included for development and demos without sending real WhatsApp messages. An external provider account is required for live delivery.

FAQ

What providers can send?

Live sending: Green API. Test mode: Mock Provider. Meta Cloud API, Evolution API, UltraMsg, Twilio, Gupshup, and Custom are registered but not available for live sending in this release.

Can I switch providers?

You keep one active provider configuration per company. You can switch that configuration between Green API and Mock Provider. Campaigns and logs stay in RelayRuntime.

Does it support Odoo Community?

Yes. RelayRuntime is built for Odoo Community as an Enterprise Messaging Runtime.

Does it support bulk messaging?

Yes. Bulk messaging and campaign history are operator workflows, including attachments and product catalogs.

Can I monitor delivery?

Yes. The Delivery Dashboard totals sent, failed, and skipped results from the provider HTTP response. It does not show WhatsApp delivered or read receipts.

Is this just a WhatsApp connector?

No. RelayRuntime adds campaign history, a delivery dashboard, message logs, and operator retry on top of WhatsApp sending for Odoo Community.

Limitations

This module does not guarantee exactly-once delivery to WhatsApp. External provider services and retry campaigns can occasionally produce duplicate messages. Very large bulk sends may take longer and can approach server time limits.

  • No built-in background queue for unattended bulk processing
  • Inbound message webhooks are not fully available in this release
  • Live delivery depends on your configured WhatsApp provider account
  • Multi-worker deployments require careful operational planning

Installation

Open RWPST RelayRuntime → Configuration → Runtime Configuration. Use Mock Provider for testing, then connect Green API for live delivery.
